API Documentation

Server-to-server INR order creation, idempotency and webhook verification.

Create order

POST /wpay-api/v1/orders Authorization: Bearer YOUR_API_KEY Idempotency-Key: shop-order-001 Content-Type: application/json { "reference": "shop-order-001", "amountMinor": "125050", "currency": "INR", "description": "Example order" }

Webhook signature

HMAC-SHA256( secret, timestamp + "." + eventId + "." + exactBodyBytes ) x-wpay-timestamp: Unix seconds x-wpay-event-id: stable UUID x-wpay-signature: v1=hex
Repeat the same idempotency key + payload after timeout. NO_ROUTE creates no order/payment link. Submitted UTR is never proof of success.
